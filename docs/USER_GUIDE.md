# 科研阅读工作台用户指南

## 1. 选择运行方式

最快的方法是打开[在线体验](https://pinkman1893.github.io/research-document-workbench/)。如果论文不适合在公共站点 origin 中处理，或模型网关不允许 GitHub Pages CORS，请下载便携版并在本机运行。

本地运行地址固定为 `http://localhost:8642/`。保持这个地址不变，浏览器才能继续读取原有 IndexedDB 数据。

## 2. 创建工作区并导入论文

首次打开会创建“默认工作区”。点击“添加文献”，或把一个或多个 PDF 拖入首页。每篇新论文进入“待读”，首次打开后转为“正在阅读”，点击“阅读完成”后进入“已完成”。

工作区支持等级分类和自定义分类。文献可在同组内拖动排序，也可拖到其他状态或分类。

## 3. 阅读与标注

- 箭头工具用于选择文字。
- 小手工具用于拖动放大的页面。
- 画笔可自由书写，再次点击画笔可更换颜色。
- 荧光笔通过选择文字创建高亮，再次点击可更换颜色。
- 橡皮擦以整次拖动为一个撤销步骤。
- 框选工具把指定区域截图加入 AI 对话，不会渲染整张高分辨率页面。
- Ctrl + 滚轮可缩放；页码框、上下页按钮和适宽按钮用于导航。

阅读位置、缩放方式、标注和高亮会自动保存。

阅读工具栏、文献菜单和弹窗支持键盘导航。隐藏的移动侧栏及收起的 AI 面板不会进入 Tab 顺序；关闭弹窗后，焦点会回到打开它的按钮。

## 4. Markdown 笔记

每篇论文有独立笔记。使用“编辑”输入 Markdown，切到“预览”查看排版。

```markdown
# 论文标题

## 结论

- **贡献**：……
- [ ] 待复现实验

> 关键限制

| 数据集 | 结果 |
| --- | --- |
| Example | 95.2 |

[P12|原文片段]
```

`[P12|原文片段]` 在预览中可点击并跳回 PDF。远程图片不会自动加载，而会显示为需要主动点击的链接。

## 5. 配置可选 AI

打开右栏设置，添加一个兼容 OpenAI Chat Completions 的模型配置：

- Base URL：通常以 `/v1` 结尾。
- API Key：由所选模型服务提供。
- 模型：使用服务实际支持的模型 ID。
- 思考强度：服务不支持 `reasoning_effort` 时可关闭。
- 视觉能力：仅在模型确实支持图片时开启。

点击“测试连接”验证。浏览器会直接请求该 Base URL，所以服务必须允许当前页面 origin 的 CORS。

启用 AI 后，论文上下文、引用、图片和对话会发送给该模型网关。项目本身没有接收这些内容的服务器。

## 6. AI 阅读工作流

- 选择原文后，可针对该段内容提问。
- 框选图表或公式后，在右栏输入问题。
- 点击“理解全文”生成结构化论文卡片。
- 生成状态依次显示读取、等待、思考与输出；可以随时停止。
- 回答中的 `[P页码|片段]` 可跳回原文。

思考过程只有在服务实际返回思考字段时才会显示。

## 7. 数据、迁移与故障排查

当前版本的数据保存在浏览器，尚无一键导出。不要清除站点数据，并保留原始 PDF。

| 现象 | 检查 |
| --- | --- |
| 工作区突然为空 | 确认地址、端口和浏览器与上次一致 |
| PDF 无法打开 | 确认通过 HTTP 运行，重新下载完整便携包 |
| AI 连接失败 | 检查 Base URL、Key、模型 ID、HTTPS 和 CORS |
| 扫描 PDF 无法理解全文 | 文件可能没有文字层，当前版本不含 OCR |
| 启动提示端口占用 | 刷新已打开的工作台，或关闭旧服务后重试 |
| 修改后页面没有变化 | 按 Ctrl+F5 强制刷新 |
